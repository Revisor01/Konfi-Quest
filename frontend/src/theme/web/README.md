# Stylesheets der Bereiche (Web-Fassung)

Je Bereich eine Datei (`chat.css`, `start.css`, `termine.css`,
`challenges.css`, `leitung.css`), eingebunden von den Web-Komponenten des
Bereichs. Es gelten dieselben Regeln wie für `../web-ansicht.css`: Klassen mit
Präfix `web-`, nur Tokens, keine Bewegung, kein Eingriff in Ionic.
`__tests__/components/webAnsichtCss.test.ts` prüft jede Datei hier.
Plan: `docs/planung/web-alle-bereiche.md`.
